# Artifice

An invitation-only circle for art collectors, artists, and galleries.

*You've always had the eye. Now you have the room.*

## About this repo

The Artifice landing page — a single self-contained HTML file (`index.html`) exported from Claude Design.

- **Live site:** enabled via GitHub Pages (see the repo's Pages settings for the URL).
- **Brand system:** see [artifice-design-system](https://github.com/solu25/artifice-design-system) for the tokens, typography, and voice this page is built on.

## Run locally

Open `index.html` in a browser, or from a terminal:

```bash
open index.html
```

No build step — everything is inlined.
